# From-Azure-to-My-Own-Server-Self-Hosting-My-Cloud-Resume-Challenge
I built my resume site for the Cloud Resume Challenge on Microsoft Azure. Then I moved it to my own hardware, running in Docker behind a Cloudflare Tunnel, and saved the $5-6 a month the Azure setup was costing me (roughly $60-70 a year) for a site that serves a few static files and one counter.
